# Web Application Test Automation (QA Automation)

Automated functional and regression testing framework built for a dynamic web application using **Python**, **Selenium WebDriver**, and **PyTest**[cite: 1].

## Features
- Automated end-to-end UI testing for user workflows (Login, Form Validation)[cite: 1].
- Implemented assertions to verify expected application behavior against actual UI results.
- Generated execution reports using PyTest to ensure frontend stability and cross-browser readiness[cite: 1].

## Tech Stack
- **Language:** Python
- **Testing Framework:** PyTest
- **Browser Automation:** Selenium WebDriver
